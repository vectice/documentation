# ❓ FAQ

<details>

<summary>How do I add a new user to my org?</summary>

Organization administrators can invite new users to their organization by clicking on invite users in the users' tab of the organization settings. You can select the list of workspaces the new user will have access to and they will be automatically added to those workspaces. It’s all existing public workspaces by default. You can also see the list of pending invitations to cancel the invitation or resend it.

</details>

<details>

<summary>How do I add a new member to my workspace?</summary>

You can add a new member to your workspace whether by choosing this workspace when inviting the user to your organization as explained in “How do I add a new user to my org?” or by clicking on “Invite members” from the member's tab of your workspace settings.

</details>

<details>

<summary>What are the types of roles a user can have inside Vectice?</summary>

The different levels of permissions in Vectice are:

* **Organization administrator**: Manages the organization-level permissions, users in the organization, and workspaces.&#x20;
* **Organization user**: Manages workspaces they are administrators of and projects in the workspaces they are members of.&#x20;
* **Workspace administrator**: Manages the workspace level permissions, users in the workspace, and projects.&#x20;
* **Workspace member**: Manages projects in the workspaces they are members of.

The organization administrator can change the users’ permissions from the “Users” tab of the organization settings.

The workspace members can change the members’ permissions from the “Members” tab of the workspace settings.

</details>

<details>

<summary>How do I get the API Token?</summary>

The API Token enables you to authenticate your requests from the Vectice Python library to the Vectice application. You can create a new API token by:

* Click on the User menu button (where your user Avatar is)&#x20;
* Select the API Tokens option
* Click the Create API Token button.

This will open a screen for you to create, then copy/download your API token.

</details>

<details>

<summary>How do I login to Vectice? </summary>

If you use a version that is hosted by Vectice, then you can log in via the URL https://app.vectice.com. This is the same URL that you need to use for authentication from the API.&#x20;

If you have a private deployment, your Vectice Admin would be able to guide you better. \
\
If you have any questions, please reach out to support@vectice.com

</details>

<details>

<summary>Where can I find my Project assets and artifacts?</summary>

In the Web UI, you can navigate to the Project from where you will see direct links to Documentation, Datasets, Models, and Runs. All your recent work could be found directly from your home page by clicking on the Vectice logo in the top-left-hand corner of the web UI.  \
\
Additionally, all assets are searchable across all your Workspaces and Projects from the Global Search located at the top of the screen.&#x20;

</details>
